Suite de herramientas, lanzadores y agentes autónomos para desarrollo full-stack, powerscaling y brainstorming continuo.

## 📂 Archivos y Lanzadores:
1. `1_INICIAR_APP_VENTANA.bat`: Inicia OpenCode como aplicación de escritorio nativa independiente (sin marcos de navegador).
2. `2_INICIAR_WEB_LAN.bat`: Inicia en modo navegador y muestra las IPs de red local (para conectar desde el Mini PC o móvil).
3. `3_ACTUALIZAR_TODO.bat`: Actualiza el motor de OpenCode y lista los últimos modelos free de OpenRouter y Gemini.
4. `4_DESPLEGAR_VERCEL.bat`: Despliegue automático a producción en Vercel con token integrado y tolerancia a discos locales/SMB.
5. `5_ARRANQUE_SILENCIOSO.vbs`: Ejecución 100% invisible sin ventana negra de consola.
